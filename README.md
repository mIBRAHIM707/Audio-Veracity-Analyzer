# AVA Acoustic Veracity Analyzer

On-premises, CPU-only, passive detection of AI-synthesized Urdu and Pakistani
Punjabi telephone speech. This is a research prototype under construction, not
a validated fraud detector or caller identity check.

## Start in any coding assistant

Read [AGENTS.md](AGENTS.md), [current state](docs/context/current-state.md), and
the relevant [PRD](_bmad-output/planning-artifacts/prd.md) and
[architecture](_bmad-output/planning-artifacts/architecture.md) sections.
Claude Code also loads [CLAUDE.md](CLAUDE.md). All clients use the same source files.

The current implementation is dataset intake tooling and development/test
infrastructure. There is no AVA API, dashboard, live-call pipeline, trained AVA
model or collected participant dataset yet. Browser tests use a controlled fixture.

## Setup and checks

Prerequisites: Git, Node.js 22, Python 3.11 (or uv to install/manage it).

```text
uv python install 3.11
npm ci
npx playwright install chromium
uv run --no-project --python 3.11 python scripts/sync_agents.py --check
uv run --no-project --python 3.11 python scripts/sync_bmad.py --check
uv run --no-project --python 3.11 python scripts/check_foundation.py
uv run --no-project --python 3.11 --with-requirements requirements-audio.txt python -m unittest discover -s tests/unit -v
uv run --no-project --python 3.11 --with-requirements requirements-pnb.txt python -m unittest discover -s tests/pnb -v
npm run test:browser
uv run --no-project --python 3.11 python scripts/repository_guard.py
```

Linux browser runners need `npx playwright install --with-deps chromium`.
These install-time downloads do not change AVA's offline runtime requirement.
If Python 3.11 is directly available, install `requirements-audio.txt` with pip
before running the unit suite, then replace the uv prefix with `python`.

Install the local pre-commit guard once per clone:

```text
uv run --no-project --python 3.11 python scripts/install_hooks.py
```

The hook examines staged files, including staged blob sizes. It is a safeguard,
not a full content privacy scanner. CI also runs the repository guard. Keep all
real audio, participant records, private manifests, consent and weights outside Git.

## Browser crawling and evidence

```text
npm run crawl -- --url http://127.0.0.1:3000 --allow-origin http://127.0.0.1:3000
```

Use only an authorized target; nothing is deployed on port 3000 by this setup.
The crawler requires exact-origin opt-in, bounds its work, and blocks cross-origin
traffic and all redirects. Read [crawler usage](scripts/browser/README.md) for
flags and limitations. Reports, screenshots and traces stay in ignored artifacts.
Use a unique output path per concurrent worker. Fixture tests do not prove AVA
product behavior, offline inference, model accuracy or PBX call survival.

## Agents and BMAD

BMAD 6.12.0 core/BMM are already installed. `.claude/skills/bmad-*` remains the
installed source, mirrored with all support resources to `.agents/skills/bmad-*`
for Codex. After intentionally editing/upgrading skills, run `scripts/sync_bmad.py`.
Do not install another copy of the same workflows as a plugin.

Eight shared roles live in [docs/agents/catalog.json](docs/agents/catalog.json).
Native Claude and Codex adapters are generated by `scripts/sync_agents.py`.
The Codex test designer uses GPT-6 Astra. Claude's test-design adapter prepares
an Astra handoff instead of pretending to run an OpenAI model inside Claude.
Other roles inherit the current model. Restart/reload clients to discover new files.

Example delegation request in Codex: “Use ava_test_designer with gpt-6-astra to
design cases for this requirement, then ava_browser_tester to execute applicable
browser cases with Playwright.” In Claude: “Use ava-test-designer to prepare the
Astra handoff; use ava-browser-tester to run the approved cases.” Availability
depends on the client/account; configuration is not execution evidence.

## Concurrent development and portable context

Use separate worktrees for Claude and Codex writers. First commit the reviewed
baseline; new worktrees do not inherit uncommitted changes. Follow
[the shared workflow](docs/engineering/workflow.md) and write one
[handoff](docs/context/handoffs/TEMPLATE.md) per task.

```text
uv run --no-project --python 3.11 python scripts/export_context.py
```

The local `.local/context/ava-context.md` bundle contains allowlisted shared
instructions, role definitions, state and requirements for another model. Review
it before sharing; no upload occurs. Source code and private datasets are excluded.

## Current data work

See [dataset intake](data/collect/README.md). The validator checks genuine-pilot
metadata, not decoded audio or complete FR-D8 lineage. Approval for participant
recording/cloning is pending. All four team members share collection duties.
The [audio preparation CLI](data/prepare/README.md) preserves originals and can
convert native PCM16 to 16 kHz mono, propose 3–6 second pause-bounded clips and
peak-normalize those copies. This does not establish model accuracy or final
training-set acceptance.

## CPU detector smoke test

The [local smoke runner](models/smoke/README.md) loads the pinned official
AntiDeepfake MMS-300M checkpoint and its trained classifier. Install its separate
optional CPU environment and run the fictional adapter tests with:

```text
uv run --no-project --python 3.11 --extra-index-url https://download.pytorch.org/whl/cpu --with-requirements requirements-model.txt python -m unittest discover -s tests/model -v
```

Weights and real reports remain outside Git. This baseline does not establish
AVA SLS training, ONNX/fairseq parity, Urdu/Punjabi accuracy or call capacity.
Follow the [active checklist](docs/context/todo.md) for current progress.
