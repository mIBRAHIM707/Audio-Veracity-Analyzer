Designed and implemented by **gpt-6-astra** on 2026-10-03 against working-tree changes based on commit `ad13029fa283183c23e84d736ac424b777e775c3`. This is actual model provenance for this session. No commits or pushes were performed for this task.

Scope: [conditioning.py](../../data/prepare/conditioning.py), optional `condition=True` integration in [prepare_audio.py](../../data/prepare/prepare_audio.py), and [fictional tests](../../tests/unit/test_audio_conditioning.py). FR-D8 motivates explicit sample/hash/speaker lineage, FR-D12 motivates shared conditioning and 3–6 second clips, FR-D13 motivates screening, FR-E3 motivates immutable external originals, and FR-W2 motivates appropriate evidence. This suite is partial supporting evidence; it does not complete pipeline parity, codec augmentation, listening QA or model validation.

The contract accepts little-endian PCM16 at 8–192 kHz, mono/stereo, downmixes by float64 arithmetic mean and resamples to 16 kHz using soxr HQ. Same-rate mono input bypasses resampling exactly. Canonicalization does not normalize amplitude. Segmentation observes canonical pre-gain samples; each chosen candidate is then peak-normalized to approximately -3 dBFS (absolute PCM16 peak 23198). Exact silence remains unchanged. Offsets refer to the **16 kHz canonical grid**, not native-file samples when rates differ.

All fixtures are mathematical tones/arrays or synthesized temporary WAVs. No corpus audio, speech recordings, network, GPU or browser is used. Temporary source/output directories clean up automatically. Numeric tests exercise actual NumPy/soxr, and integration tests exercise real report/WAV output. No numerical processing is mocked. All cases are P0 for this bounded implementation; browser applicability is none.

Original clip-ID lineage is also asserted. uv's no-project warning did not affect the result.

The numerical tolerances test specific synthetic signals and the pinned local implementation. They are not comprehensive frequency-response specifications, cross-platform bit-identity guarantees, listening results, or proof that resampling never overshoots. The explicit square-wave test confirms saturation is accounted for. Peak normalization is not perceptual loudness normalization or denoising; it can amplify background noise in quiet clips.

Integration compares each actual candidate with the separately invoked canonicalize/normalize contract to prove the wiring and ordering; the independent tone, attenuation, downmix and peak tests assess those numerical functions. Canonical-to-native offsets require rate conversion; records must not imply an exact original byte slice after resampling/gain. Publisher genuine/language labels and unassigned splits remain provenance, not independently verified language, consent, perceptual acceptance or training readiness.

Remaining hardening includes broad sample-rate/filter sweeps, long-file memory/latency benchmarks, malicious filesystem races, concurrent output publication, interrupted disk writes, complete genuine/synthetic parity and train/serve integration. Existing preparation tests cover additional source-integrity/path cases; this suite does not replace them. No per-file human approval gate is inferred from these tests.
